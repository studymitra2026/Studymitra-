Chapter 1: Algebra — Detailed Notes

These notes are written in simple language for revision and practice. Use them with your prescribed syllabus and classroom material.

Study method: First understand the rule, then solve the example without looking, and finally practice similar questions.

1. Basic Algebra

Algebra is a branch of mathematics in which letters such as x, y, a, b represent numbers or unknown quantities.

Terms and expressions

An algebraic expression is made from constants, variables and mathematical operations.

Examples: 3x + 5, 2a² − 7a + 1, x² + xy + y².

  • Constant: A fixed number, such as 5 or −3.
  • Variable: A quantity represented by a letter, such as x.
  • Coefficient: The number multiplying a variable. In 7x, 7 is the coefficient.
  • Like terms: Terms having the same variables with the same powers, e.g. 3x and 8x.
  • Unlike terms: Terms with different variables or powers, e.g. 3x and 3x².
Example: Simplify 4x + 7x − 3 + 5.
= 11x + 2
Answer: 11x + 2

2. Laws of Indices

Indices (powers) tell how many times a number is multiplied by itself.

aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
(ab)ᵐ = aᵐbᵐ
(a/b)ᵐ = aᵐ/bᵐ
a⁰ = 1 (a ≠ 0)
a⁻ᵐ = 1/aᵐ
Example 1: 2³ × 2⁴ = 2⁷ = 128
Example 2: 5⁷ ÷ 5³ = 5⁴ = 625
Example 3: (3²)³ = 3⁶ = 729
Example 4: 2⁻³ = 1/2³ = 1/8

3. Algebraic Identities

Identities are equations that remain true for all permitted values of the variables.

(a+b)² = a² + 2ab + b²
(a−b)² = a² − 2ab + b²
(a+b)(a−b) = a² − b²
(a+b)³ = a³ + 3a²b + 3ab² + b³
(a−b)³ = a³ − 3a²b + 3ab² − b³
a³+b³ = (a+b)(a²−ab+b²)
a³−b³ = (a−b)(a²+ab+b²)
Example: Expand (x+5)².
= x² + 2(x)(5) + 25
= x² + 10x + 25
Example: Factorise x² − 49.
= x² − 7²
= (x−7)(x+7)

4. Factorisation

Factorisation means writing an expression as a product of simpler factors.

Common factor method

6x² + 9x = 3x(2x + 3)

Difference of squares

x² − 16 = (x−4)(x+4)

Quadratic expression

x² + 5x + 6 = (x+2)(x+3)
Tip: After factorising, multiply the factors again to check your answer.

5. Quadratic Equation

A quadratic equation is generally written as ax² + bx + c = 0, where a ≠ 0.

Quadratic formula

x = [−b ± √(b² − 4ac)] / 2a

The quantity D = b² − 4ac is called the discriminant.

Value of DNature of roots
D > 0Two distinct real roots
D = 0Two equal real roots
D < 0No real roots (roots are complex)
Example: Solve x² − 5x + 6 = 0.
Here a=1, b=−5, c=6.
x = [5 ± √25−24]/2 = [5 ± 1]/2.
Therefore x = 3 or x = 2.

6. Logarithms

If aˣ = N, then logₐN = x, where a is the base.

logₐ(MN) = logₐM + logₐN
logₐ(M/N) = logₐM − logₐN
logₐ(Mⁿ) = n logₐM
logₐ1 = 0
logₐa = 1

Common logarithm

Logarithm with base 10 is commonly written as log.

Natural logarithm

Logarithm with base e is written as ln, where e is approximately 2.718.

Example: log₁₀(1000) = 3, because 10³ = 1000.
Example: log₂(8) = 3, because 2³ = 8.

7. Permutation and Combination — Basic Concepts

Factorial: n! = n(n−1)(n−2)...3×2×1.

0! = 1
nPr = n!/(n−r)!
nCr = n!/[r!(n−r)!]

Permutation is used when order matters. Combination is used when order does not matter.

Example: 5! = 5×4×3×2×1 = 120.
Example: 5C2 = 5!/(2!3!) = 10.

8. Binomial Theorem — Basic Form

For a positive integer n:

(a+b)ⁿ = ⁿC₀aⁿ + ⁿC₁aⁿ⁻¹b + ⁿC₂aⁿ⁻²b² + ... + ⁿCₙbⁿ

For small powers, the familiar identities are useful.

Example: (x+1)² = x² + 2x + 1.

9. Partial Fractions — Introduction

Partial fractions express a rational algebraic expression as a sum of simpler fractions.

For distinct linear factors, a form such as
1/[(x+a)(x+b)] = A/(x+a) + B/(x+b)
may be used, where A and B are constants determined by solving equations.

This topic should be practiced with your teacher's prescribed types of problems.
